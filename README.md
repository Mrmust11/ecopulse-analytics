**EcoPulse Analytics** is an interactive data visualization platform designed to track and analyze global carbon dioxide (CO_2) emissions and primary energy consumption trends across 50+ nations. Built with speed and interactivity in mind, it provides immediate insights into historical and present-day environmental indicators.

---

## ✨ Key Features

- **🌐 Multi-Country Comparison:** Select and compare historical emissions and energy consumption across multiple nations simultaneously.
- **📈 Dynamic Visualizations:** Interactive time-series line charts and grouped bar plots powered by Plotly.
- **⚡ Real-Time OWID Data:** Pulls up-to-date, verified datasets directly from *Our World in Data*.
- **📊 Quick Metrics Dashboard:** Instant overview of year ranges and total countries selected.

---

## 🛠️ Tech Stack

- **Frontend / Framework:** [Streamlit](https://streamlit.io/)
- **Data Manipulation:** [Pandas](https://pandas.pydata.org/)
- **Data Visualization:** [Plotly Express](https://plotly.com/python/)
- **Data Source:** [Our World in Data (OWID)](https://github.com/owid/co2-data)
